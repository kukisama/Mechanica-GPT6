# MECHANICA · GPT-6 Astra（Max）能力展示

**以四冲程柴油机 3D 仿真为载体，展示 AI 编程模型从自然语言需求到可运行应用的端到端开发能力。**

> 表面上，这是一个能旋转、剖视、观察四冲程运动的柴油机网页；项目的核心目的，则是展示 **GPT-6 Astra 在 Max 级别下，以约 3,000 点数投入，实际交付了什么**。

## 项目定位：发动机是载体，模型能力是主角

MECHANICA 是一次具体的 AI 编程能力展示。在 VS Code 的 GitHub Copilot 智能体环境中，使用 GPT-6 Astra，以四冲程柴油机为题材，完成了三维建模、运动逻辑、交互界面、自动化测试、调试和离线打包。

这个项目需要从两个层面理解：

- **作为应用**：它是一个真正使用 Three.js / WebGL 2 渲染的四冲程柴油机三维教学网页，不是二维动画、CSS 伪 3D 或预渲染视频。
- **作为展示案例**：它用于观察模型能否把简短需求转化为可操作、可检查、可交付的软件，而不只是生成一张好看的界面或一段示例代码。

**AI 参与的是开发过程，不是网页运行过程。** 成品网页不调用大模型、不持续消耗模型点数，也不需要 API 密钥；交互和仿真都在浏览器本地执行。

## 体验成品

**已有构建产物时，双击 `dist/index.html` 即可离线使用。** 这个单文件内含三维引擎、样式和全部模型逻辑，可以单独复制到其他电脑。

从仓库获取源码后，先按下方“本地开发”安装依赖并执行 `npm run build`，再打开生成的 `dist/index.html`。三维模型由程序生成，运行时不需要下载外部模型、纹理、字体或访问远程 CDN。

请使用支持 WebGL 2 的新版 Edge、Chrome 或 Firefox。浏览器需要允许图形渲染；如果上下文初始化失败，页面会明确显示错误，不会冒充运行成功。

## 仿真网页的功能

- 立体发动机：气缸、带凹腔活塞、活塞环、活塞销、定长连杆、曲轴配重、齿圈飞轮、气门、弹簧及喷油器。
- 鼠标/触摸旋转、缩放与平移；立体、正视、侧视预设；自动环绕及全屏。
- 剖视、透明透视、实体三种显示模式；部件选择高亮和随模型投影的标签。
- 完整 720° 进气 → 压缩 → 做功 → 排气循环；气流、喷油和燃烧颜色可视化。
- 播放、暂停、10° 步进、时间轴拖拽、冲程定格、600–2400 rpm 调节和四档演示倍速。
- 压力、温度、位移、容积、气门状态，以及联动的 p–V 教学示意。
- 中文响应式界面、键盘操作、减少动态效果偏好支持、WebGL 丢失/恢复处理。

## 技术栈与本地开发

| 层次 | 实现 |
| --- | --- |
| 界面与交互 | 原生 HTML / CSS / JavaScript |
| 三维渲染 | Three.js + WebGL 2，程序建模，无外部三维资产 |
| 运动与教学热力模型 | 独立、确定性的 JavaScript 模块 |
| 构建交付 | Vite + vite-plugin-singlefile |
| 自动化测试 | Node.js 内置 `node:test` + Playwright / Chromium |

要求 Node.js 22.12+。首次执行 `npm install` 安装依赖，之后 `npm run dev` 启动开发服务器。

- `npm run build`：生成 `dist/index.html` 离线单文件。
- `npm run preview -- --port 4173`：预览已构建的页面。
- `npm test`：执行运动学与热力教学模型的单元测试。
- `npx playwright install chromium`：首次安装浏览器测试所需的 Chromium。
- `npm run test:e2e`：测试 WebGL 渲染、真实网格连接误差、交互、窄屏、离线文件及错误恢复。先执行构建。
- `npm run check`：依次执行单元测试、构建与浏览器测试。

根目录的 `index.html` 是开发入口，需要通过 Vite 运行；**无需服务器直接打开的是 `dist/index.html`**。本项目不需要后端、账户、API 密钥或环境变量。

## 仿真边界：能力展示不等于工程认证

本项目的目标是展示模型开发能力并解释柴油机原理，**不是专业发动机设计软件、CFD 求解器或经过实机标定的数字孪生**。以下参数与近似应和页面效果一起理解：

- 气缸直径 86 mm、行程 90 mm、连杆中心距 150 mm、压缩比 18:1，单缸排量约 0.523 L。都是本演示的设定，不代表某个量产型号。
- 曲柄滑块几何精确计算活塞位置；连杆两端与活塞销、曲柄销保持连接。机械位置每 360° 重复，完整工作过程每 720° 重复。
- 0° 为进气上止点。气门开闭按理想四冲程划分，不包含实际发动机的配气重叠。气门驱动按角度直接控制，省略凸轮、摇臂和正时传动。
- 喷油窗口 350°–388° 为可视化教学设定，燃烧示意从 360° 开始。燃烧是压燃，不使用火花塞。
- 压缩/膨胀使用定比热理想气体近似：比热比 1.35；柴油循环定压加热截止比 2.2。下止点泄压、进排气及残余气体温度采用简化处理。
- 气缸内径与活塞行程按统一比例建模；活塞凹腔、端口、弹簧等局部细节为教学造型，不用于制造。容积读数基于理想等截面气缸，不积分造型网格。
- 1× 演示为真实时间的 1/60；默认 1200 rpm 显示为 20 rpm，完整循环约 6 秒。转速只改变时间推进，不改变静态理想热力曲线。后台标签恢复不会追赶跳过的时间。
- 颜色、粒子为原理说明，并非流体或燃烧求解。忽略真实燃烧化学、流动、散热、摩擦、负载调速，不预测实际功率、油耗或排放。

## 文件结构

- `src/simulation.js`：与渲染无关的确定性运动/教学热力模型。
- `src/engine-scene.js`：程序建模、灯光、材质、相机、粒子与三维标签。
- `src/main.js`：交互控制、动画时钟、遥测图表、错误处理。
- `src/style.css`：桌面/移动端布局和交互样式。
- `tests/`：Node 单元测试与 Playwright 真实浏览器测试。
- `vite.config.js`：将全部运行资源内联到单个 HTML。
